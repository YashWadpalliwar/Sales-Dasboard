# 📊 Profit Analysis Dashboard using Microsoft Power BI

## Overview

This project presents an interactive **Profit Analysis Dashboard** developed in **Microsoft Power BI**. The dashboard transforms raw business data into meaningful visual insights, helping organizations analyze profitability across multiple business dimensions.

## ✨ Features

* 📍 City-wise Profit Analysis
* 🏢 Department-wise Profit Analysis
* 👥 Client-wise Profit Analysis
* 💳 Payment-wise Profit Analysis
* 📞 Contact-wise Profit Analysis
* 📅 Interactive Date Timeline
* 🔍 Dynamic Filters and Slicers
* 📈 Interactive Charts and Visualizations

## 🛠️ Tech Stack

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Cleaning & Transformation

## 📊 Dashboard Insights

* Compare profits across different cities.
* Analyze department-wise business performance.
* Track client contribution to overall profit.
* Evaluate payment method profitability.
* Explore trends using interactive filters.

## 🎯 Project Objective

The objective of this project is to demonstrate how **Business Intelligence (BI)** tools can transform raw data into actionable insights, enabling better strategic and operational decision-making.
